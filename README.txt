ДИПЛОМНЫЙ ПРОЕКТ: Разработка стенда полунатурного моделирования системы управления движением квадрокоптера
========================================

========================================
1. СИСТЕМНЫЕ ТРЕБОВАНИЯ
========================================
1.1. Операционная система:
    - Windows 10/11 (64-bit) 

1.2. Минимальные требования (проверено на ноутбуке):
    - Процессор: Intel Core i3 / i5 любого поколения
    - ОЗУ: 8 ГБ 
    - Видеокарта: встроенная Intel HD Graphics / Iris Xe
    - Место на диске: 5 ГБ для проекта + 20 ГБ для UE4

1.3. Рекомендуемые требования (для комфортной работы):
    - Процессор: Intel Core i5 или AMD Ryzen 5
    - ОЗУ: 16 ГБ
    - Видеокарта: NVIDIA GTX 1050 или лучше
    - Место на диске: 10-25 ГБ для проекта

1.4. Программное обеспечение:
    - Unreal Engine 4.27 (в проекте используется эта версия)
    - AirSim 
    - Python 3.8.0 
    - Visual Studio 2022 
    - .NET Framework 4.8

========================================
2. УСТАНОВКА UNREAL ENGINE 4.27
========================================
2.1. Скачать Epic Games Launcher с официального сайта: https://store.epicgames.com/ru/download
2.2. Установить и запустить лаунчер (Создать аккаунт)
2.3. Перейти на вкладку Unreal Engine → Библиотека →  установить Unreal engine версии 4.27
2.4. Установка (потребуется ~20 ГБ)

========================================
3. НАСТРОЙКА PYTHON И ВИРТУАЛЬНОГО ОКРУЖЕНИЯ
========================================
3.1. Установить Python 3.8.0:
    - Скачать с официального сайта: https://www.python.org/downloads/release/python-380/
    - ВАЖНО: При установке отметить галочку "Add Python to PATH"
    - Проверить установку: Открыть командную строку (cmd) и ввести:
      python --version (должно показать Python 3.8.0)

3.2. Распаковать архив проекта:
    - Распаковать в папку БЕЗ русских символов и пробелов
    - Пример: C:\diploma\project\

3.3. Открыть командную строку (cmd) в папке проекта:
    - Зажать Shift + ПКМ в папке → "Открыть терминал"
    - Или через cd: cd C:\diploma\project\

3.4. Создать виртуальное окружение в папке проекта:
     python -m venv .venv

3.5. Активировать виртуальное окружение:
    .venv\Scripts\activate    
    После активации слева появится (.venv)

3.6. Обновить pip (менеджер пакетов):
    python -m pip install --upgrade pip    

3.7. Установить зависимости из requirements.txt:
    pip install -r requirements.txt    


========================================
4. УСТАНОВКА VISUAL STUDIO 2022 ДЛЯ UNREAL ENGINE
========================================
4.1. Скачать и установить Visual Studio Installer:
    - Сайт: https://visualstudio.microsoft.com/ru/vs/older-downloads/
    - Выбрать версию: Visual Studio 2022 Community 

4.2. Запустить Visual Studio Installer и нажать "Изменить" (Modify)

    - "Разработка классических приложений .NET"
    Дополнительно установить необходимые пакеты: 
    - Пакет SDK для Windows(10/11)
    - Средства разработки .NET Framework 4.8.1
    - Адаптер тестирования Unreal Engine

4.4 Нажать "Изменить" (Modify/Install) 


========================================
5. НАСТРОЙКА AIRSIM В ПРОЕКТЕ UNREAL ENGINE
========================================

5.1. Подготовка проекта Unreal Engine:
    - Запустить Unreal Engine 4.27
    - Создать или открыть существующий проект  

5.2. Создание C++ класса (для инициализации Visual Studio):
    - В меню UE4 выбрать: "File" → "New C++ Class"
    - Выбрать родительский класс (например, "None" или любой другой)
    - Нажать "Create Class"
    - Автоматически откроется Visual Studio 2022
    - Это необходимо для создания файлов решения (.sln) и привязки Visual Studio к проекту

5.3. Установка плагина AirSim в проект:
    - Скачать или склонировать репозиторий AirSim:
      git clone https://github.com/Microsoft/AirSim.git
      Или скачать ZIP-архив с GitHub

- Скопировать папку "AirSim\Unreal\Plugins\AirSim" 
      в папку "Plugins" собственного проекта UE4
      
      Путь к плагину в проекте должен быть:
      [Проект]\Plugins\AirSim\

      5.4. Подключение плагина в файле проекта:
    - Открыть файл [Проект].uproject в текстовом редакторе (Notepad++ ,Блокнот или visual studio)
    - Добавить секцию "Plugins":
    
      {
        "FileVersion": 3,
        "EngineAssociation": "4.27",
        "Category": "",
        "Description": "",
        "Modules": [
          {
            "Name": "Проект",
            "Type": "Runtime",
            "LoadingPhase": "Default"
          }
        ],
        "Plugins": [
          {
            "Name": "AirSim",
            "Enabled": true
          }
        ]
      }
    
    - Сохранить файл

    5.5. Генерация файлов Visual Studio:
    - Закрыть Unreal Engine и Visual Studio (если открыты)
    - Найти в папке проекта файл [Проект].uproject
    - Нажать на него правой кнопкой мыши
    - Выбрать: "Generate Visual Studio project files"
    - Дождаться завершения процесса 
    
  5.6. Открытие и сборка проекта в Visual Studio:
    - Запустить файл [Проект].sln 
    - В Visual Studio убедиться, что вверху выбран:
      Режим: "Local windows debugger" 
      Платформа: "Win64"
    - В меню выбрать: "Сборка" → "Собрать решение" 
    - Дождаться успешной сборки (обычно 5-15 минут)

    5.7. Запуск и настройка проекта:
    - Нажать F5 или "Local Windows Debugger" для запуска
    - Unreal Engine откроется с проектом
    - В редакторе UE4 выбрать: "Window" → "World Settings"
    - В разделе "Game Mode" выбрать:
      GameMode: "AirSimGameMode"
    - Убедиться, что в качестве устройства выбран дрон:
      

5.8. Настройка конфигурации AirSim (если необходимо):
    - В папке проекта создать папку "Documents\AirSim" (если нет, обычно создается автоматически)
    - Создать файл settings.json:
    
      {
        "SettingsVersion": 1.2,
        "SimMode": "Multirotor",
        "ViewMode": "FlyWithMe",
        "ClockType": "SteppableClock",
        "Vehicles": {
          "Drone1": {
            "VehicleType": "SimpleFlight",
            "AutoCreate": true,
            "X": 0,
            "Y": 0,
            "Z": -10,
            "Yaw": 0
          }
        }
      }
    
    - Сохранить файл по пути: C:\Users\[Имя]\Documents\AirSim\settings.json

    5.9. Запуск симуляции:
    - В UE4 нажать кнопку "Play" (или Alt+P)
    - Должен появиться дрон (обычно красный или синий)
    - Дрон должен зависнуть в воздухе, готовый к управлению

========================================
6. ЗАПУСК PYTHON-СКРИПТА
========================================
6.1. Убедиться, что Unreal Engine запущен и симуляция активна
6.2. Открыть новое окно командной строки (cmd) в папке diplomaa
6.3. Активировать виртуальное окружение:
    .venv\Scripts\activate
6.4. Запустить скрипт управления дроном:
    python main.py
6.5. Дрон должен начать выполнять программу (двигаться, снимать видео и т.д.)

========================================
7.1. В консоли Python должны появиться сообщения о подключении к AirSim

7.3. Если используется YOLO - должно появиться окно с видео и детекцией
